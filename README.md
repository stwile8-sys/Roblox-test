# +1 Launch Power

Roblox-игра: каждую секунду сила выстрела растёт на +1, игрока тряпичной куклой запускает из пушки
над 10 зонами до края мира. Монеты — на апгрейды, затем перерождение.

Всё создаётся кодом, без Roblox Studio: GitHub Actions проверяет код (luau-lsp), собирает место через
Rojo и публикует через Roblox Open Cloud.

## Код
- `src/shared/Config.luau` — весь баланс: зоны, апгрейды, подарки, коды, товары.
- `src/server/World.luau` — мир кодом: площадка с 8 пушками, 10 зон, декор, ворота, отметки дистанции.
- `src/server/Game.luau` — сила, запуск, проверка дальности (клиент не может прилететь дальше расчёта), награды, перерождение, подарки, ежедневка, коды, друзья, лидерборд.
- `src/server/Shop.luau` — геймпассы и товары за Robux.
- `src/server/Data.luau` — сохранения с блокировкой сессии.
- `src/client/Flight.luau` — полёт рэгдолла, руление, кольца, отскоки, камера.
- `src/client/Main.client.luau` — интерфейс.

## Публикация
Пуш в `main` — проверка, сборка и публикация. Другие ветки — только проверка.
Товары и геймпассы создаёт `tools/assets/pipeline.py` (ветка `assets`).
