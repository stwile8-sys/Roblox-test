# Frontier Empires

Многопользовательская экономическая стратегия для Roblox. Всё создаётся кодом, без Roblox Studio: GitHub Actions проверяет код (luau-lsp), собирает место через [Rojo](https://rojo.space) и публикует его через Roblox Open Cloud.

## Как устроено

- **Вход и миры.** Публичный сервер — только «вход» (`src/server/Router.luau`): он находит мир игрока и переносит его туда. Мир — постоянный приватный сервер на 20 участков (`src/server/Data/Worlds.luau`). Первый вошедший поднимает сервер, и тот загружает города всех членов мира.
- **Сохранения** — `src/server/Data/Profiles.luau`: блокировка сессии, автосохранение, сохранение при выходе и остановке сервера.
- **Карта** — `src/server/World/`: лоу-поли сетка 5×5 (хаб в центре, 4 рынка по углам, 20 участков в 9 биомах), горы, река, озеро, море.
- **NPC-работы** — `src/server/Hub/Jobs.luau`: 7 коротких заданий в хабе, перерыв 30 с.
- **Город** — `src/server/City/`: дороги, зоны (жилые, торговые, промышленные) с ростом домов как в Cities: Skylines, особые здания (ферма, лесозаготовка, каменоломня), жители, еда, налоги, спрос.
- **Рынок** — `src/server/Economy/Market.luau`: заявки игроков и NPC, комиссия, доставка. Оффлайн-прогресс — `Offline.luau`.
- **Клиент** — `src/client/`: интерфейс, режим стройки (палец, мышь, геймпад), туториал, 2 настройки графики.
- **Переводы** — `src/shared/Lang/Strings.luau`: 11 языков.

## Публикация

При каждом пуше в `main` код проверяется, игра собирается и публикуется в место (Universe 1195242587, Place 3327609598). Нужен секрет репозитория `ROBLOX_API_KEY` (Open Cloud, доступ «места вселенной» → «Написать»). Пуш в другие ветки — только проверка кода.
