# Chrono Heist Tycoon — прогресс сборки

ТЗ v2.0 (все ответы заказчика учтены) — см. историю чата; договор модулей — docs/ARCH.md.
Работаем в ветке `dev`. Плейс закрыт (Private). Релиз = слияние в `main`.

## Готово
- Каркас: default.project.json (портрет, ночное освещение), docs/ARCH.md
- shared: Config/Palette, Config/Game (весь баланс), Config/Assets (ID, заполняет пайплайн), Net, Lang/L
- server/Data/Profiles: сохранения User_<id>, блокировка сессии, MemoryStore-сессии, офлайн-кража (атомарно), журнал краж
- server/Game: Ctx (контекст, состояние, тосты), Bases (владение, стены, щит, якоря, маяк), Economy (доход, конвейер,
  апгрейды, стройка, энергия), Raid (скан, вторжение, взлом, кража, перенос, дубинка, ловушки, замок, месть),
  Progress (ребёрс, квесты, серия, достижения, титан, пропуск, VIP)

## План правок (10.11, после отзыва с телефона) — делать по порядку
1. Мосты-кольцо пересекают базы: в Island.luau концы боковых мостов считать от центра базы к центру соседней:
   A = Pi + (Pj−Pi).Unit*62, B = Pj − (Pj−Pi).Unit*62.
2. Конвейер убрать полностью (на хабе не строить Belt, в Economy не спавнить; клиентская подсказка buy не нужна).
3. «Пещера удачи» вместо конвейера, в центре хаба:
   - Island: под кристаллом холм-пещера (пастельные цилиндры, 4 пандуса), тёмный «вход» на вершине, невидимый
     CaveTrigger (CanTouch) над входом; кристалл поднять выше (y≈24). Подземная комната CaveRoom под островом (y≈−80):
     пол, стены, светящиеся кристаллы, точка CaveSpawn, поток воздуха (частицы вверх).
   - server/Game/Cave.luau: касание триггера → проверки (не несёт добычу, кулдаун 6 с, есть место, хватает Cash);
     цена = Game.CAVE_COST*(1+ребёрсы) (CAVE_COST=250); списать, выбрать редкость по весам 60/25/10/4/1 и существо;
     телепорт в комнату (S.serverMoved), позы, Fx "caveFall"; через 1.2 с Popup "caveReveal" {id} — СНАЧАЛА карточка;
     выброс потоком воздуха — только ПОСЛЕ карточки: когда игрок закрыл её (Act "caveDone") или через 6 с;
     выброс = телепорт над входом + скорость вверх 90, Fx "caveLaunch"; give() → сразу на базу; квест buy, passXp, аналитика.
     State: caveCost. Это не платный рандом (только игровой Cash).
   - Клиент: над входом Billboard «Пещера удачи · $цена»; попап caveReveal — праздничная карточка: цвет редкости,
     существо крупно, имя, плашка редкости, конфетти и звук.
4. Замок — кнопка на базе: BaseBuilder делает Model "LockButton" (тумба с большой круглой кнопкой) у ворот внутри,
   локально (14, 0, −46). Сервер: касание хозяином → та же логика, что Ctx.actions.lock (кулдаун). Из HUD «Замок» убрать,
   клавишу F убрать. Кнопка «Действие» видна только для взлома/клетки. Обучение шаг 4: стрелка к кнопке замка.
5. Дубинка — предмет: сервер при появлении персонажа кладёт Tool «Дубинка» (Handle: деревянная рукоять + шар,
   без мешей) в Backpack; Tool.Activated на сервере → Raid.bat(S). Клиент: Backpack CoreGui включить.
   Из кнопки «Действие» удар убрать.
6. Проверить luau-lsp, пуш в dev, дождаться публикации, отписаться пользователю.
